# ArchPatterns

Android architecture practice around live stock data.

- **Repository sample** — Finnhub REST, Room cache, domain repository, details/history screens
- **MVI sample** — Finnhub WebSocket client, `StockIntent` / `StockState`, live ticker UI

## Stack

Kotlin, Jetpack Compose, Retrofit, Room, WebSockets, Hilt.

## Run

Open the project in Android Studio and run the `app` configuration.

```bash
./gradlew :app:assembleDebug
```
